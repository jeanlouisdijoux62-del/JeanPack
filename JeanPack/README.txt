JeanPack – Pack complet généré automatiquement

Contenu:

1) Site HTML
   - Ouvre `JeanPack/site/index.html` dans un navigateur.
   - Navigation responsive, bouton menu pour mobile, formulaire simulé.

2) Logiciel Python
   - Ouvre un terminal dans `JeanPack/python_app`
   - Lance :

```bash
python main.py
```

3) Outil Windows
   - Double-clique sur `JeanPack/windows_tools/outil_jean.bat` ou lance-le depuis PowerShell.

Notes:
- Le formulaire du site montre une confirmation accessible (simulation).
- Pour créer une archive zip du dossier, demandez-moi et je la prépare.
